html-modules Identity

Component identity vs registration name

A component's exported identity is not its tag. ui.html exports a component whose identity is card; each importer decides what to call it, exactly as import { card as profileCard } would in JavaScript. A registry accepts a constructor only once, so every registration is a fresh subclass of the definition's one base element.

One definition, five tags

<html-import src="./components/ui.html" as="shop"></html-import>                  <!-- shop--card -->
<html-import src="./components/ui.html">
  <html-binding export="card" element="note-card"></html-binding>              <!-- note-card -->
</html-import>

const ui = await HTMLModules.load('./components/ui.html');
ui.card.define('profile-card');                                                 // profile-card
HTMLModules.bind(ui, { as: 'bound' });                                          // bound--card, …
customElements.define('fancy-card', class extends ui.card.element {             // fancy-card, with behaviour
  connectedCallback() { this.shadowRoot.querySelector('article').dataset.fancy = ''; }
});

    Definitions from JavaScript

    The same representation can be written by hand. defineHTMLComponent() is what both the loader and the compiler call.

    import { defineHTMLComponent } from '@johnhenry/html-modules/runtime';

const priceTag = defineHTMLComponent({
  name: 'price-tag',
  template: '<span part="amount"><slot></slot></span> <small>USD</small>',
  styles: [':host { font-variant-numeric: tabular-nums; font-weight: 650; }'],
});
priceTag.define('price-tag');
priceTag.define('cost-tag');

      The default export has no name

      <html-export name="default"> is a module's default export, like export default in JavaScript. Its definition has no identity of its own (name is null), it is not in the components manifest, and a namespace import does not register it: the importer names it with <html-binding export="default" element="…">. A bare name means the same thing; mind templating that can render name="", which also becomes the default. To export a component under a name and as the default, add default next to a real name: <html-export name="callout" default>.
