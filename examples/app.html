A small app: reading list

Built from HTML modules: the components are app/ui.html, the seed data is app/data.html, the brand colour is a stylesheet in app/theme.html, and the only JavaScript is the behaviour in app/reading-list.js, which extends the app-shell template. Add, move, rate and filter books; your changes are kept in this browser.

How it is put together

<html-import src="./app/theme.html"><html-binding export="brand" adopt></html-binding></html-import>
<html-import id="data" src="./app/data.html">
  <html-binding export="books"></html-binding>
  <html-binding export="shelves"></html-binding>
</html-import>
<html-import src="./app/reading-list.js" as="app"></html-import>

<app--reading-list id="list"></app--reading-list>
<script type="module">
  const { bindings } = await document.getElementById('data').ready;
  await customElements.whenDefined('app--reading-list');
  document.getElementById('list').load(bindings);
</script>
