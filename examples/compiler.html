html-modules Compiler

The compiler

Browsers cannot import an .html file as a module, and this library does not try to make them. Instead, html-module compiles an HTML module into an ordinary ES module that exports the same HTML Component Definitions the runtime builds. The output imports only the small runtime, registers nothing on import, and needs no loader.

Same module, two paths

Both frames contain identical markup. The left one loads the HTML modules at runtime with <html-import>; the right one has no loader at all, only native import of the compiled files and definition.define(tag).

Runtime: compiler/runtime-frame.html

Compiled: compiler/compiled-frame.html

    Using compiled modules
    
      
    
        
    
          
    As ES modules: definitions, not registrations
    

    import { card, components } from './compiled/ui.js';

card.define('esm-card');            // you choose the tag
customElements.get('card');         // undefined: nothing self-registers
    
          <esm-card>Defined from the compiled module.
        
    
        
    
          
    With <html-import>, through the components manifest
    

    <html-import src="./compiled/ui.js" as="cui"></html-import>
    
          
          <cui--callout> from the compiled file.
        
    
      
    
      
    
        
    
          
    --format register --as reg: registers on import
    

    import './compiled/icons.register.js';   // defines <reg--star>, <reg--heart>, …
    
          
    
        
    
        
    
          
    --format register --as ico --delimiter -
    

    import './compiled/icons.dash.register.js';   // defines <ico-star>, <ico-heart>, …
