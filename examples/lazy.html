html-modules Lazy loading

Lazy loading

With load="lazy" (on an import, or for the whole document in <html-import-settings>), nothing is fetched until one of the import's tags is actually used. Then the module loads, its tags are registered, and the elements that were waiting upgrade in place. The network panel records every module this page has fetched, from the browser's own resource timing. 

<html-import-settings load="lazy"></html-import-settings>

<html-import src="./components/ui.html" as="ui"></html-import>          <!-- waits for any <ui--…> -->
<html-import src="./components/shelf.html" as="shelf"></html-import>
<html-import src="./components/icons.html" as="icon"></html-import>
<html-import src="./components/tip.html">                                <!-- waits for exactly <lazy-tip> -->
  <html-binding export="default" element="lazy-tip"></html-binding>
</html-import>
<html-import src="./components/gallery.html" as="gallery" load="eager"></html-import>  <!-- the attribute wins -->
<html-import id="gone" src="./components/tally.html" as="gone"></html-import>
<html-import id="manual" src="./components/hint.html"></html-import>    <!-- nothing to watch: only .load() -->

Steps

    1. The first <ui--…> element

    A namespace import does not know its export names before loading, so it waits for any tag starting with ui--.

      2. A tag inside a component's shadow root

      shelf.html's template uses <icon--heart>. Adding a <shelf--row> loads shelf.html; its shadow root then contains the page's first <icon--…>, which loads icons.html. Shadow roots created by html-modules components (open or closed) are watched as well as the document.

        3. A binding with element=

        With <html-binding> children, the import waits for exactly the tags they bind.

          4. A module's own lazy import

          gallery.html was loaded eagerly, but its own <html-import-settings load="lazy"> makes its import of rating.html lazy: it is fetched when a <rate--stars> first appears in a <gallery--wall>. 

          <!-- gallery.html -->
<html-import-settings load="lazy"></html-import-settings>
<html-import src="./rating.html" as="rate"></html-import>
<html-export name="wall"><template>… <rate--stars></rate--stars> …</template></html-export>

            5. el.load()

            #manual has no as and no bindings, so there is no tag to wait for. load() loads any import now.

              6. Disconnecting before it loads

              Removing a lazy import that has not loaded stops the watching. Putting it back resumes it (and an element already present triggers it).

                7. From JavaScript

                const handle = HTMLModules.import('./components/vault.html', { as: 'vlt', load: 'lazy' });
handle.state;   // "waiting"; also handle.ready, handle.load(), handle.cancel()

                  Network

                  HTML modules this page has fetched (PerformanceObserver, resource entries), in ms since the page started.

                  Imports

                  Not watched: shadow roots created by other code, other documents (iframes), and template contents until they are cloned into a watched tree.
