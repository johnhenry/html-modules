Live CDN routing with mport v2

This page needs network access. Declarative imports of npm: and jsr: specifiers go through fromMport(createRouter(...)): mport looks the range up in the npm or JSR registry, then races esm.sh against jsDelivr's +esm build with HEAD probes, falling back to unpkg. For an offline version with local mirrors, see Routing with mport. 

import { createRouter, fallback, race, esmSh, jsDelivr, unpkg, jsr } from 'mport';
const router = createRouter({
  '*': fallback(race(esmSh(), jsDelivr({ esm: true })), unpkg()),
  '@std/*': jsr(),
});
defineModuleElements({ loader: createLoader({ router: fromMport(router) }) });
