web-module-graph Compiled import map (CLI)

Compile routing to an import map

The CLI asks a router once, ahead of time, and writes a standard import map and a lockfile. The files on this page were produced by web-module-graph build from cli/modules.config.js (a basicRouter with ordered candidates, a file-system probe, a scope and a merged map). The test suite checks they are up to date.

Commands

# from the package root
node bin/web-module-graph.js build --config examples/cli/modules.config.js \
  --out examples/cli/importmap.json --lock examples/cli/modules.lock.json
node bin/web-module-graph.js build --config examples/cli/modules.config.js --html --out examples/cli/importmap.html
node bin/web-module-graph.js resolve @tokens greet@1.0.0 @lib/ --config examples/cli/modules.config.js

Using the compiled map at runtime

      
Two loaders consume the same compiled map: one with importMap, one with router: importMapRouter(map). Both reproduce the build-time decisions without re-running the router.
