html-modules Quickstart

Quickstart

Write components in an ordinary HTML file with <html-export>. Import the file with <html-import src as>. Every export becomes a native custom element, named <namespace--export>. There is no build step and no custom JavaScript loader.

The result

These elements appear in the page before the import that defines them. They start as unknown elements and upgrade natively when ui.html has loaded.

Hello from an HTML module This card is a <template> in components/ui.html, stamped into a shadow root. Exported as card, used as <ui--card>.
Say hello

The markup

<script type="module" src="/node_modules/@johnhenry/html-modules/src/browser.js"></script>

<html-import src="./components/ui.html" as="ui"></html-import>

<ui--card>
  <span slot="title">Hello from an HTML module</span>
  This card is a <template> …
</ui--card>
<ui--button>Say hello</ui--button>

And the export it uses, from components/ui.html:

<html-export name="card">
  <style>:host { display: block; border: 1px solid var(--border); … }</style>
  <template>
    <article part="card">
      <header part="title"><slot name="title"></slot></header>
      <slot></slot>
      <footer part="footer"><slot name="footer"></slot></footer>
    </article>
  </template>
</html-export>
