Router chaining

A Router answers one question: where does this bare specifier live? It returns a resolution, or null for "not mine". chainRouters() asks each in turn. Everything here runs offline: the mport adapter is fed an mport-compatible stand-in that races two local "CDN" mirrors.

A chain, traced

importMapRouter(pins)→basicRouter(@internal/*)→toRouter(partials)→mportRouter(local mirrors)

Each specifier is loaded through createLoader({ router: chain }). The trace shows which routers were asked and which one answered. importModule calls are counted: mport already evaluated the module, so the loader reuses it.

    basicRouter patterns

    basicRouter({ routes: {
  '*': 'https://esm.sh/', '@std/*': 'https://jsr.example/', 'react*': 'https://react-cdn.example',
  'jsr:': (rest) => `https://jsr.example/${rest}/mod.js`, exact: 'https://exact.example/',
} })

    Ordered fallback with httpProbe()

    Array routes list candidates in order; a probe checks each until one passes. httpProbe sends HEAD and retries with GET on 405. The "down" mirror is simulated with a 503 by the probe's fetch; the backup mirror answers 405 to HEAD.

    The mport adapter

    mportRouter({ MPortURL, mport: { cdns }, match }). The stand-in has mport's contract: MPortURL(options) returns (pkg) => [module, url].
