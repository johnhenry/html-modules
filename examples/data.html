Data binding in templates

{{attribute}} in a template's text or attribute values reads the host element's attribute. Bound nodes are patched in place when it changes. There is no eval, no expression language and no innerHTML: it works under a strict CSP with Trusted Types. props="name count:number" on the export also makes attributes reflect as typed properties.

Edit the attributes

Try javascript:alert(1) as the website: the attribute is removed, never set. A name like <img src=x onerror=alert(1)> is shown as text.
