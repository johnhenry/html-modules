Mixing HTML and JS-authored components

<html-import> also takes JavaScript modules, loaded with native import(). A JS module says which of its exports are components; nothing else is ever registered, so VERSION never becomes <ui--version>. Consumers cannot tell which technology a component was written in.

      3. Any class, bound by name
      
      
      A plain JS module needs no manifest if the page names the export and the tag:
      

      <html-import src="./components/widgets.js">
  <html-binding export="ClickCounter" element="tap-counter"></html-binding>
</html-import>

      4. HTML template, JS behaviour
      
      
      
        A JS module can load an HTML module, extend a definition's .element (which stamps the template), and export the result.
        The template and its styles stay in HTML; only the behaviour is JavaScript.
