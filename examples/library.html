html-modules Component library

Writing a component library in HTML

A library is an HTML file of <html-export> elements. A component export holds one <template>; <style> elements next to it become the component's styles, shared by every instance. An export with only <style> is a stylesheet; one with a JSON script is data. Anything not inside an export is private to the file.

2. What the module exports

      
await HTMLModules.load('./components/ui.html') returns a namespace shaped like an ES module: one HTML Component Definition per component (camelCase), the data, the default, and a components manifest keyed by export name.

      

      
    
    
    

    
    
      
    3. Modules that import modules
    
      
    
        rating.html imports icons.html as icon and uses <icon--star> in its template. That import is the
        module's own: it is bound when one of the module's components is registered, and the stylesheet it adopts from
        themes.html applies inside the module's components only.

    4. A barrel: components/kit.html
    
      
    
        <html-export src="…"> re-exports every component of another module, like export * from.
        <html-export src="…" name="rating" import="stars"> re-exports one, renamed. The source can be a JS module,
        so a JavaScript component joins the library too. A barrel can have exports of its own.
