Live CDN routing with mport

This page needs network access. Bare npm specifiers go through chainRouters(mportRouter({ MPortURL })), which races jsDelivr, JSPM and unpkg with the real mport package (v1 API) and returns the winning URL with the already-evaluated module. For an offline version with a stand-in, see Router chaining.
