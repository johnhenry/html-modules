Scoped custom element registries

Custom element names are global, so two versions of a library that both use <icon--star> inside their components collide. With <html-import-settings registry="scoped"> in a module, that module's own imports are registered in a registry of their own, used by the shadow roots of its components. Both versions below render their own icons on one page. Needs a browser with scoped custom element registries; elsewhere this page says so.
