html-modules Component library

A component library made of HTML modules

tiny-ui is written as HTML modules: every component is a <template export> with its own shadow styles, tokens are a <style export> the page adopts, icons are <svg export>, helpers are a module script, and one behavioural component comes from JS through the same barrel.
