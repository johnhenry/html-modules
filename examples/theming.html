Adopted stylesheets and theming

A <style export> becomes a constructed CSSStyleSheet. adopt puts it in document.adoptedStyleSheets; the same object can also be shared with any number of shadow roots, and editing it updates them all.

One sheet, many shadow roots

Each <theme-swatch> stamps a template into its shadow root, and the page adds the exported shadowBase sheet to every root. Edit it: replaceSync() on the shared object restyles all of them at once.

Fallback: no CSSStyleSheet

A loader whose window has no CSSStyleSheet (like some server or test environments) exports { kind: "stylesheet", cssText }. A custom interpret can also return the raw <style> element. adoptStyleSheet() accepts both and appends a <style> to the document instead.
