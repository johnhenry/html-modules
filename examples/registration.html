Registration

Importing never registers anything by itself. element= and <define-element> are explicit, separate steps, and the same export can be registered under as many tags as you like.

One class, four tags

Each tag keeps its own count. The first registration uses Counter itself; later names get a subclass, because a constructor can only be defined once per registry.

    Insert a <define-element name="reg-late" component="LateGreeting"> first: it waits on scope.whenDeclared(). Then insert the import that declares LateGreeting, and it registers.
