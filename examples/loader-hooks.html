Loader hooks: a module graph in memory

Every step of the loader is replaceable. This page serves a small module graph from an in-memory file system with custom fetch, parseHTML, importModule, scriptURL, interpret and detectType. Edit a file and run it again: each run uses a fresh loader and logs every hook call.
