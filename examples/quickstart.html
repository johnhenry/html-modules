html-modules Quickstart

Quickstart

The smallest useful page: one <script src="src/browser.js">, a page import map, and declarative imports. Bare specifiers go through the page import map via import.meta.resolve.

A <template export="Card"> re-exported as Panel by a barrel (@demo/ui → components/barrel.html). Default export registered with a <define-element> that appears before its import.

The markup

<script type="importmap">{ "imports": { "@demo/ui": "./components/barrel.html" } }</script>
<script type="module" src="../src/browser.js"></script>

<module-import from="@demo/ui">
  <module-binding name="Panel" element="demo-panel"></module-binding>
  <module-binding name="theme" adopt></module-binding>
  <module-binding name="Counter" element="demo-counter"></module-binding>
  <module-binding name="Counter" as="Counter2" element="other-counter"></module-binding>
</module-import>
<define-element name="demo-strong" component="Strong"></define-element>
<module-import from="./components/ui.html" default="Strong"></module-import>
<module-import id="ns" from="./components/ui.html" namespace="UI"></module-import>

See components/barrel.html, components/ui.html and components/counter.js.
