html-modules Errors

Errors

Every failure is reported where it happened. A failed module fires error on its <html-import> and rejects el.ready. A failed binding fires error on its <html-binding>, which bubbles through the import, while the import's other bindings still apply. Each case below runs when the page loads; the listener is one error handler on document.

Retrying after a failure, and loader events

Failed loads are removed from the cache, so a later import tries again. This uses its own createHTMLModules() instance whose fetch hook fails the first request (no real network error), with an onEvent log.
